# An_Ninh_Mang_Nhom3

Dự án **KHCN-Security**: Website quản lý đề tài KHCN sinh viên với Django, PostgreSQL, JWT, RBAC và HTTPS/TLS.

Mã nguồn nằm trong thư mục [KHCN-Security](KHCN-Security/). Khi chạy các lệnh Django, vào thư mục có `manage.py`.

Đọc **[README hướng dẫn đầy đủ](KHCN-Security/README.md)** để xem:

- Công cụ, công nghệ, cài đặt trên máy mới và vận hành HTTP/HTTPS.
- Cơ sở lý thuyết JWT, RBAC, TLS gắn với code thực tế.
- Thiết kế kiến trúc, ERD, luồng xử lý, ma trận quyền và các API.
- Kiểm thử, giới hạn bảo mật, kịch bản demo và câu hỏi bảo vệ sản phẩm.

Không đưa `.env`, mật khẩu, token, private key hoặc database dump lên GitHub.
